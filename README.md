# Portuguese-Bank-Marketing-Project
Machine Learning project to predict term deposit subscription using Random Forest, SMOTE and XGBoost.

# 📊 Portuguese Bank Marketing Prediction
# 📌 Objective

Predict whether a customer will subscribe to a term deposit using Machine Learning.

# 🔍 Models Used

# Logistic Regression

# Decision Tree

# Random Forest

# Random Forest (SMOTE)

# XGBoost

# Threshold Tuning

# 📈 Best Performance

Accuracy: 83.4%

ROC-AUC: 0.788

Recall (Yes Class): 71% (after threshold tuning)

Helps bank marketing team:

Identify high-potential customers

Reduce unnecessary calls
